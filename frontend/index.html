Connect a New App

1

Choose your stack

Add to requirements.txt:

guardian-tap @ git+https://github.com/bnarasimha21/guardian-tap-python.git@main

Install via npm:

npm install github:bnarasimha21/guardian-tap-typescript
2

Add two lines to your server file

from guardian_tap import attach_observer attach_observer(app)

Works with FastAPI apps (WebSocket, SSE, and REST JSON).

import { attachObserver } from 'guardian-tap'; attachObserver(app);

Works with Express apps. No other changes needed, app.listen() works as before.

3

Deploy your app, then register it here
